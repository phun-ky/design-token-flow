Token flow

Each pill is a design token, and each line joins an alias to the token it references, ending at the values on the right. Drag or scroll to move; zoom with the buttons, Ctrl or Cmd and the wheel, or a trackpad pinch.

Arrow keys pan, Shift and an arrow key pan further, plus and minus zoom, 0 resets to 100 percent, the page width, and F fits the flow to the screen.
